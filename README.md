# EDM 即時預覽編輯器

製作給某公司用簡易版 EDM 編輯器

## 使用方法

* 下載或複製專案中的 index.html，在任意瀏覽器直接開啟使用。
* 或開啟專案對應網站進行編輯後下載。

## 操作指南

### 左側側邊欄

* 點擊**新增圖文區塊**可新增一個區塊
* 點擊**新增分隔線**可增加一條分隔線
* 長按區塊標頭的 `☰` 圖示可進行**上下拖曳排序**。
* 點擊區塊右上角的「**刪除**」按鈕可移除該區塊。

### EDM 前言
在 EDM 最頂部新增**大標題**與**標題內文**，如:

*某某商品預購中！！！*

*又來到一年一度的某某活動，讓我們一起共襄盛舉.....*

### 圖文區塊
* **圖片網址**: 圖片本身的網址
* **圖片對應網站**: 點擊圖片要開啟網站的網址
* **文字位置**:將圖片的敘述放在上方或下方
* **文字內容**:圖片敘述
* **按鈕文字**:輸入文字後會增加一個按鈕，點擊按鈕會開啟圖片對應網站設定的網站

### 即時預覽與匯出
* 所有的編輯會即時在右側預覽。
* 「檢視 / 複製原始碼」按鈕開起彈窗，可點擊「一鍵複製原始碼」或「下載 HTML 檔案」。
